# Income Guidance Architecture

Paytm Sense Income Guidance extends the GROW pillar without changing the
existing financial engine.

```text
Existing income analysis
  -> backend income pathways
  -> career profile
  -> career memory recall
  -> Groq career evaluation
  -> structured guidance response
  -> optional career memory save
```

## Data Flow

The frontend calls `GET /income-pathways` to display backend-derived pathway
targets. It then submits `POST /income-guidance` with a selected pathway,
career profile, demo user id, and explicit memory consent.

FastAPI owns all orchestration. React never calls Groq or Cognee directly.

## Memory

Career memory is handled by `backend/app/services/career_memory.py`.

When memory consent is enabled, Paytm Sense stores concise career context:
education, skills, preferences, selected income pathway, target additional
income, recommended roles, skill gaps, and action plan.

It does not store API keys, credentials, full transaction history, or raw bank
account data. Memory is scoped by the supplied user id, currently a local demo
identifier generated by the frontend and stored in browser local storage.

If Cognee is unavailable, guidance still runs with the current profile. The
service falls back safely and does not expose technical memory errors to users.

## AI Evaluation

`backend/app/ai/career_guidance.py` uses Groq when `GROQ_API_KEY` is configured.
The model receives:

- selected backend income pathway
- target additional income
- career profile
- recalled career memory

The AI returns structured JSON for roles, skill gaps, search queries, action
plan, and application strategy. Groq is instructed not to invent companies,
salaries, application links, or claim access to current vacancies.

If Groq is not configured, a deterministic local guidance fallback keeps the
demo flow usable from the submitted profile and backend target.

## Endpoint

`POST /income-guidance`

Request:

```json
{
  "user_id": "demo-user",
  "pathway_id": "comfortable",
  "remember_profile": true,
  "career_profile": {
    "education_status": "Student",
    "employment_status": "Student",
    "skills": [{"skill": "JavaScript", "proficiency": "Beginner"}]
  }
}
```

Response includes:

- selected pathway
- profile summary
- recommended roles
- skill gaps
- action plan
- application strategy
- memory status

## Secrets

Required secrets stay server-side:

- `GROQ_API_KEY`
- `COGNEE_API_KEY`

Do not expose these in frontend code.
